# Kodexis · Landing Trazza

Landing page de Kodexis para presentar **Trazza**, construida con React 18+, Vite, TypeScript y Tailwind CSS.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Estructura

```text
src/
  components/
    layout/     # Header, Footer, Layout
    sections/   # Hero, Features, Waitlist
    ui/         # Button, FeatureCard, ThemeToggle, Input, Select, Logo
  contexts/     # ThemeProvider (light/dark)
  data/         # Contenido estático
  types/        # Interfaces TypeScript
  App.tsx
  main.tsx
  index.css
```
